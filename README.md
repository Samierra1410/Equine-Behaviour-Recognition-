## Overview

This repository contains the full pipeline for automated classification of equine-human interaction behaviors from video. The system integrates three complementary computer vision modalities — YOLOv8 (spatial relationships), MediaPipe (human pose), and AP-10K (equine pose) — to extract 35 discriminative features per frame, which are then classified using a two-stage hierarchical CatBoost architecture.

**Key results on 50,270 annotated samples across 28 videos:**

- 88.5% balanced accuracy across 6 fine-grained behaviors (oracle routing)
- 73.2% balanced accuracy for 3-category parent classification
- 85.0% recall on safety-critical avoidant behaviors (only 3.8% of dataset)
- Hierarchical approach outperforms flat classification by +25.1 percentage points

---

## Behavioral Taxonomy

The pipeline classifies interactions into **3 parent categories** and **6 fine-grained sub-behaviors**:

| Parent      | Sub-Behavior       | Description                                             |
| ----------- | ------------------ | ------------------------------------------------------- |
| Affiliative | Affiliative-Active | Active approach, touch, grooming, joint movement        |
| Affiliative | Affiliative-Subtle | Relaxed proximity without deliberate contact initiation |
| Neutral     | Neutral-Horse      | Horse grazing, self-grooming, self-directed attention   |
| Neutral     | Neutral-Human      | Human passive observation, waiting                      |
| Avoidant    | Avoidant-Horse     | Horse withdrawal, ear pinning, stress displays          |
| Avoidant    | Avoidant-Human     | Human backing away, protective gestures                 |

## Pipeline Architecture

```
Script 01  →  Script 04  →  Script 05  →  Script 06    ← MAIN pipeline (required)
Script 03  ↗  (optional: AP-10K equine pose, requires mmpose)
Script 02     (standalone relational features, not used downstream)
```

### Script Descriptions

| Script                           | Name                | Role                                                                             |
| -------------------------------- | ------------------- | -------------------------------------------------------------------------------- |
| `01_mediapipe_extractor.py`      | MediaPipe Extractor | Extracts YOLOv8 spatial + MediaPipe human pose features from raw videos          |
| `02_fast_relational_features.py` | Relational Features | Standalone relational feature extraction (not used downstream)                   |
| `03_ap10k_horse_pose.py`         | AP-10K Extractor    | Extracts equine pose features via AP-10K HRNet (optional, requires mmpose)       |
| `04_complete_fixed_pipeline.py`  | Pipeline Assembly   | Merges BORIS annotations with extracted features; produces labeled dataset       |
| `05_ultimate_merger.py`          | Feature Merger      | Fuses YOLO/MediaPipe and AP-10K features; falls back gracefully if AP-10K absent |
| `06_hierarchical_catboost.py`    | Classifier          | Two-stage hierarchical CatBoost; trains and evaluates all models                 |

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/Samierra1410/Equine-Behaviour-Recognition-
cd equine-behavior-classification
```

### 2. Install core dependencies

```bash
pip install -r requirements.txt
```

### 3. Install mmpose (optional — Script 03 only)

Script 03 and AP-10K equine pose extraction are **optional**. Scripts 01, 04, 05, and 06 all run without mmpose. Script 05 automatically detects the absence of AP-10K outputs and falls back to YOLO+MediaPipe features only.

To enable full AP-10K equine pose extraction:

```bash
# Install mmcv first — adjust torch/cuda versions to match your environment
pip install mmcv==2.1.0 -f https://download.openmmlab.com/mmcv/dist/cpu/torch2.0/index.html

# Then install mmpose
pip install mmpose
```

### 4. Download model weights

**AP-10K HRNet weights** (Script 03 only):

- Download `hrnet_w32_ap10k_256x256.pth` from the [AP-10K Model Zoo](https://github.com/AlexTheBad/AP-10K)
- Rename to `hrnet_w32_ap10k.pth` and place in `models/`

**YOLOv8 weights** (`yolov8n.pt`):

- Downloaded automatically by `ultralytics` on first run — no manual step needed.

### 5. Add your videos

Place raw `.mp4` interaction videos in `og_videos/`. These files are not included due to privacy and facility agreements.

## Running the Pipeline

Run scripts in order. Each script reads from the previous step's output.

```bash
# Step 1: Extract YOLO spatial + MediaPipe human pose features from videos
python scripts/01_mediapipe_extractor.py

# Step 2 (optional): Extract AP-10K equine pose features
python scripts/03_ap10k_horse_pose.py

# Step 3: Align features with BORIS behavioral annotations
python scripts/04_complete_fixed_pipeline.py

# Step 4: Fuse all feature modalities into unified dataset
python scripts/05_ultimate_merger.py

# Step 5: Train and evaluate the hierarchical CatBoost classifier
python scripts/06_hierarchical_catboost.py
```

**Running without AP-10K:** Simply skip Script 03. Script 05 will fall back to YOLO+MediaPipe features automatically.

## Results Summary

### Six-Behavior Hierarchical Classification

| Behavior           | Precision | Recall | F1    |
| ------------------ | --------- | ------ | ----- |
| Affiliative-Active | 95.1%     | 76.0%  | 84.5% |
| Affiliative-Subtle | 56.4%     | 88.4%  | 68.4% |
| Neutral-Horse      | 94.0%     | 78.3%  | 85.3% |
| Neutral-Human      | 69.4%     | 90.4%  | 78.5% |
| Avoidant-Horse     | 100%      | 99.7%  | 99.8% |
| Avoidant-Human     | 97.0%     | 98.1%  | 97.5% |

### Pipeline Performance

| Stage                               | Balanced Accuracy | Overall Accuracy |
| ----------------------------------- | ----------------- | ---------------- |
| Stage 1: 3-category parent          | 73.2%             | 63.8%            |
| Stage 2A: Affiliative sub-behaviors | 82.2%             | —                |
| Stage 2B: Neutral sub-behaviors     | 84.3%             | —                |
| Stage 2C: Avoidant sub-behaviors    | 98.9%             | —                |
| **Full pipeline (6 behaviors)**     | **88.5%**         | **80.9%**        |

Evaluated via stratified 5-fold cross-validation. Video-level grouped CV: 85.2% ± 1.1%. Leave-one-video-out: 83.7% ± 2.4%.

The hierarchical approach outperforms flat 6-way classification by **+25.1 pp** (63.4% → 88.5% balanced accuracy).

## Feature Modalities

35 features total extracted per frame across three modalities:

| Source         | Features                                                                | Count |
| -------------- | ----------------------------------------------------------------------- | ----- |
| YOLOv8-nano    | Euclidean distance, bounding box positions, areas, detection confidence | 12    |
| MediaPipe Pose | Nose, shoulder, wrist positions; body height, speed, center             | 15    |
| AP-10K HRNet   | Head centroid, elevation angle, body angle, ear angle, alertness score  | 8     |

Ablation study result: AP-10K features contribute most critically (−13.1 pp when removed), followed by YOLO (−8.0 pp) and MediaPipe (−4.8 pp).

## Dataset

- **28 videos**, ~85 minutes of naturalistic horse-human interaction footage
- **4 recording locations**: Norway, Iceland, Saxtorp (Sweden), TorHall (Sweden)
- **5 horse breeds**: Icelandic, Fjord, Swedish Warmblood, Norwegian Fjord, Gotland pony
- **50,270 temporal samples** extracted at 3 fps within annotated behavior intervals
- **Annotations**: BORIS v8.15; inter-rater reliability κ = 0.78 (95% CI: 0.74–0.82)
- **Class imbalance**: 166.6:1 ratio between most common and rarest category

Raw videos are not publicly available due to privacy and facility agreements. Behavioral annotation CSVs are included in `data/boris_csvs/`. Processed feature representations are available from the corresponding author upon reasonable request.

repository due to size limits. It will be available on Zenodo upon
